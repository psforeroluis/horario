Recuperación de horas

Introduce la entrada y la salida de cada día y descubre cuánto tiempo hay que recuperar el viernes a partir de las 16:00.

¿Cómo se calcula?

De lunes a jueves cuenta todo el tiempo entre la entrada y la salida, salvo la franja 13:00–15:00, que solo cuenta si se activa «Comió en la oficina». El viernes cuenta desde la entrada hasta las 16:00. Las horas de más de un día compensan las de menos de otro. Un día marcado como festivo o ausencia justificada no se exige ni se suma. Lo que falte hasta las horas exigidas es lo que hay que recuperar el viernes a partir de las 16:00. Los datos se guardan solo en este navegador.
