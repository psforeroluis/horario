# Recuperación de horas

Aplicación web (un solo archivo, `index.html`) que calcula cuántas horas debe recuperar un trabajador el viernes a partir de las 16:00.

Horario: lunes a jueves 09:00–13:00 y 15:00–19:00; viernes 08:00–16:00 (40 h semanales).

- Por cada día se indica la entrada y la salida (el viernes, solo la entrada; cuenta hasta las 16:00).
- De lunes a jueves, la franja 13:00–15:00 solo cuenta como trabajo si se marca «Comió en la oficina».
- Las horas de más un día compensan las de menos de otro.
- Un día marcado como festivo o ausencia justificada no se exige.

Uso: abrir `index.html` en el navegador. Los datos se guardan en el propio navegador.
